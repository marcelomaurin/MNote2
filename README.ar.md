# MNote2

MNote2 هو محرر نصوص وأكواد متعدد المنصات تم تطويره باستخدام Lazarus/Free Pascal. يجمع التطبيق بين التحرير عبر علامات تبويب، وتشغيل السكربتات، وأدوات قواعد البيانات، وتكامل الذكاء الاصطناعي، واستخراج المستندات، وأدوات صوتية مساعدة.

إصدار الشيفرة الحالي: **2.56**.

## الميزات الرئيسية

### المحرر والملفات

- محرر متعدد التبويبات مبني على SynEdit.
- دعم تمييز الصياغة لـ Pascal وPython وJava وSQL وPHP وC وأنواع أخرى يتم ضبطها عبر قوائم مساعدة.
- البحث والاستبدال والنسخ/اللصق والتراجع/الإعادة وتحديد الكتل وضبط الخط.
- فتح الملفات وحفظها في علامات تبويب مستقلة.
- استخراج النص من ملفات PDF وDOC وDOCX.
- حفظ سجل المحادثة لكل ملف باستخدام ملفات .RIA المرتبطة.
- تكامل مع تنظيم المجلدات والمشاريع.

### المشاريع والمجلدات وتحليل الذكاء الاصطناعي

- مسح المجلدات وتحليل الملفات المصدرية والمستندات.
- إنشاء ملخصات تقنية لكل ملف وتخزينها في ذاكرة مؤقتة .RIA.
- إنشاء تحليلات موجهة للأسئلة وتخزينها في ذاكرة مؤقتة .PIA.
- حذف ذاكرة .RIA عند تغير الملف المصدر بعد إنشاء الملخص.
- إنشاء خريطة ذهنية نصية لتجميع النقاط المهمة ذات الصلة بالسؤال.
- تجاهل ملفات التخزين المؤقت .RIA و .PIA تلقائيًا أثناء التحليل الجديد.
- دعم امتدادات مثل .pas و.pp و.lfm و.lpr و.ini و.json و.yml و.yaml و.php و.htm و.html و.js و.xml و.c و.cpp و.txt و.doc و.docx و.pdf و.sql و.jsp و.py و.cob و.md.

### الذكاء الاصطناعي

- عميل ذكاء اصطناعي مدمج داخل TCHATGPT، بالإصدار الداخلي 1.5.
- مقدمو الخدمة المدعومون: OpenAI وOpenRouter وCerebras وLocal/llama.cpp المتوافق مع واجهة /v1/chat/completions.
- النماذج الموجودة في الشيفرة تشمل: gpt-3.5-turbo وgpt-4 وgpt-4-turbo-preview وgpt-4o وgpt-o3-mini وgpt-4.1 وgpt-4.1-mini وgpt-5.
- كما توجد نماذج محلية/Ollama مثل llama3.2:3b وQwen وDeepSeek.
- دعم النموذج المخصص عند ضبطه.
- إعداد نقطة النهاية المحلية عبر IPLocalIA.
- يتم حفظ سجل المحادثة وخريطة الذاكرة والتفكير في ملفات .RIA.
- تصنيف استمرارية المحادثة.
- إعداد السياق من السجل وخريطة الذاكرة والمشروع وقاعدة البيانات والملفات المحللة.
- إجراءات مدعومة بالذكاء الاصطناعي، بما في ذلك توليد استعلامات SQL وإنشاء هياكل الجداول.

### Python والأتمتة

- تنفيذ كود Python المفتوح في المحرر عبر PythonEngine.
- مسار DLL الخاص بـ Python قابل للضبط.
- توجيه مخرجات التنفيذ إلى منطقة النتائج.
- فحص المتغيرات العامة والمحلية بعد التنفيذ.
- يمكن ضبط سكربتات خارجية لـ run وdebug وclean وinstall وcompile.
- توجد أمثلة في sample/python وsample/gcc، بالإضافة إلى سكربتات مساعدة في src.

### قاعدة البيانات وMQuery2

يعمل MQuery2 كمدير SQL مدمج.

- الاتصال بـ MySQL وPostgreSQL وSQLite باستخدام Zeos.
- ضبط مكتبات DLL/SO الخاصة بـ MySQL وPostgreSQL وSQLite.
- التنقل في أشجار قواعد البيانات والجداول والحقول والعروض والإجراءات والدوال والمشغلات والتسلسلات بحسب الاتصال النشط.
- تنفيذ SQL حر من المحرر المدمج.
- توليد SQL من الجداول المحددة.
- إنشاء الجداول من مجموعات بيانات CSV.
- إنشاء مستخدمين في PostgreSQL.
- توليد قواميس بيانات لـ PostgreSQL وSQLite.
- توليد قوائم الاعتماديات والمفاتيح الخارجية لـ SQLite وPostgreSQL.
- تكامل مع الذكاء الاصطناعي لتحليل SQL واقتراح التحسينات وتنسيق الاستعلامات والإجابة على الأسئلة اعتمادًا على DDL والاعتماديات.
- يوفر TSQLiteDb اتصال SQLite والمعاملات وpragmas الموصى بها والتنفيذ المجهز والاستعلامات المساعدة.
- يفتح TProjetoDB مشروع SQLite ويتحقق من الجداول ويحمّل البيانات الوصفية والإعدادات.

### أدوات الصوت

- يرسل ToolsFalar النص عبر TCP إلى خدمة تحويل النص إلى كلام مثل srvFalar.
- يتصل ToolsOuvir عبر TCP لاستقبال الأوامر والرسائل الخارجية.
- يمكن تفعيله تلقائيًا عند البدء حسب الإعدادات.
- يتم ضبط IP والمنفذ من الواجهة.

### التثبيت والتوزيع

- مثبت Windows يعتمد على Inno Setup في instalador/MNote2.iss.
- إصدار مثبت Windows: 2.56.
- ينسخ MNote2.exe وملفات DLL وملفات .dci وقوائم .txt وسكربتات .bat والأمثلة وقاعدة البيانات الافتراضية.
- ينسخ قاعدة البيانات الافتراضية إلى C:\db.
- يتضمن خيارًا بعد التثبيت لتشغيل srvFalar_1.4.exe.
- توجد الحزم والملفات الثنائية التاريخية داخل bin.
- يحافظ buildlinux.sh على تدفق بناء Linux/deb.

## بنية المشروع

- src/MNote2.lpr: نقطة دخول تطبيق Lazarus.
- src/main.pas: النموذج الرئيسي، علامات التبويب، المحرر، التحميل/الحفظ، الدردشة، السجل، الأدوات والتكامل العام.
- src/classes/item.pas: يغلف كل علامة/عنصر قابل للتحرير، وتنفيذ Python والسكربتات المهيأة.
- src/classes/chatgpt.pas: عميل HTTP لمزودي الذكاء الاصطناعي.
- src/setmain.pas: الإعدادات العامة والتخزين في mnote.cfg.
- src/config.pas: نموذج إعدادات السكربتات وDLL وAI وقواعد البيانات وأدوات TCP.
- src/folders.pas: إدارة المجلدات، تحليل الملفات، ذاكرات .RIA/.PIA، وتحليل المشروع بالذكاء الاصطناعي.
- src/ia.pas: واجهة الذكاء الاصطناعي مع السجل وخريطة الذاكرة والتفكير والاستمرارية والإجراءات.
- src/mquery2/mquery2.pas: مدير قواعد البيانات وSQL.
- src/sqlite_db.pas: غلاف SQLite.
- src/uprojetodb.pas: تحميل مشروع SQLite والبيانات الوصفية.
- src/uPdfText.pas: استخراج نص PDF داخلي بسيط.
- src/uDocText.pas: استخراج نص DOC/DOCX.
- src/toolsfalar وsrc/toolsouvir: أدوات صوت TCP.
- db/projeto_padrao.db: قاعدة بيانات المشروع الافتراضية.
- screenshots: الصور المستخدمة في README.
- instalador: سكربتات التثبيت على Windows.
- sample: أمثلة Python وC ومعالجة الصور.
- libs وsqlite وtools: مكتبات وأدوات خارجية مرفقة.

## المتطلبات

### التطوير

- Lazarus IDE وFree Pascal Compiler.
- حزم Lazarus المستخدمة في المشروع، بما في ذلك LCL وSynEdit وTAChart وIndy وZeos وRX وPython4Lazarus وlNet ومكونات إضافية مذكورة في src/MNote2.lpi.
- مكتبات قواعد البيانات حسب الحاجة: SQLite وMySQL client وPostgreSQL/libpq/ODBC بحسب الإعداد.
- Python 3 متوافق مع DLL المهيأة عند تفعيل تنفيذ Python.
- Inno Setup لإنشاء مثبت Windows.

### الاستخدام

- Windows وLinux هما الهدفان الرئيسيان الظاهران في المشروع.
- ملفات .doc الكلاسيكية تتطلب Windows مع تثبيت Microsoft Word.
- ميزات الذكاء الاصطناعي تتطلب token/provider مضبوطًا أو خادمًا محليًا متوافقًا.
- أدوات الصوت تتطلب تشغيل خدمة TCP المقابلة.

- الملفات الأخيرة.
- سكربتات run/debug/clean/install/compile.
- رمز AI والمزوّد.
- نقطة نهاية AI المحلية.
- مسارات DLL الخاصة بـ Python وMySQL وPostgreSQL.
- بيانات اتصال MySQL وPostgreSQL وSQLite.

## الاستخدام السريع

1. افتح MNote2.
